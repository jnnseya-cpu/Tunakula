# Product Requirements

The governing specification is **PRD-NZG-001 — Tunakula Product Requirements & Production Specification,
v4.2 (2 October 2026)**, owned by Justin Nseya, Group Chief Executive.

The document is classified *Confidential — internal and contracted developers only* and is therefore not
committed to this repository. Obtain it from the product owner. Code and ADRs reference it by section
number (e.g. "§19.4"); when the PRD changes under change control, update the affected references.

Sections implemented in this repository so far: §8.2 and §9.5 (RBAC policy layer), §10 and §11 (order
aggregate and custody gates, see ADR 0004), §12.2 (order channel attributes), §7.2 (Country Profile schema), §7.3 (PaymentConnector /
PayoutConnector ports), §19 (money model, Currency Registry, FX, cash rounding, ledger journals),
§20.1–20.5 and §20.7 (payment taxonomy, states, routing and fallback, certification suite),
§32.2 (core guard), §33 (multi-market synthetic test matrix).
